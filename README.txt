# Contact Links website

Static website ready for deployment.

## Files
- index.html — landing page
- privacy.html — draft privacy policy (review before publishing)
- terms.html — draft terms (review before publishing)
- styles.css — responsive styling
- assets/ — supplied Contact Links icon and screenshots

## Before launch
1. Replace the App Store placeholder link in index.html when the public App Store URL is available.
2. Review privacy.html and terms.html against the actual app behavior and business/legal requirements.
3. Deploy the folder to Vercel or another static host.
4. Connect contactlinks.in and www.contactlinks.in.
5. Keep the existing email DNS/MX records for support@contactlinks.in intact.
